# Security Policy

Thank you for helping keep mal-icons and its users safe.

## Supported versions

Security fixes are applied to the `main` branch first. Once public packages are
released, fixes will be backported to the latest supported minor version when
practical.

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability.

Use GitHub's private vulnerability reporting or the repository Security Advisory
flow. If that is unavailable, contact the maintainers through the mal-icons
GitHub organization with enough detail to reproduce and assess the issue.

Helpful reports include:

- The affected package and version or commit.
- A clear description of the vulnerability and its impact.
- Reproduction steps or a minimal proof of concept.
- Any known mitigations.

We aim to acknowledge valid reports within 5 business days, coordinate a fix,
and credit reporters when they want attribution.
