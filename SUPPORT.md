# Support

Use the right channel so maintainers and contributors can help quickly.

## Questions and usage help

Use GitHub Discussions when it is enabled. If Discussions are not available,
open an issue and choose the closest template.

## Bugs

Open a bug report with:

- The affected package, framework, and version.
- A minimal reproduction or small code sample.
- Runtime, browser, Node, Bun, and framework versions.
- Expected behavior and actual behavior.

## Feature requests

Open a feature request describing the use case, the API you want to use, and any
alternatives you considered.

## Security issues

Do not report security issues in public issues. Follow [SECURITY.md](./SECURITY.md).
